# Changelog

## 0.2.1

- Aligned the README, CLI, package, plugin, marketplace, release, and repository
  descriptions around Repocast's general-purpose product and technical demo scope.

## 0.2.0

- Generalized walkthroughs with document, terminal, browser, image, GIF, and video scenes.
- Added themes, size presets, focus effects, annotations, captions, watermarks, imported
  audio, webcam overlays, trimming, fades, GIF output, and configurable encoding.
- Added strict validation, Draft 2020-12 JSON Schema, JSON CLI results, dry runs, browser
  composition checks, production quality gates, contact sheets, checksums, and TTS caching.
- Made terminal failures fatal by default, final delivery atomic, scratch cleanup guarded,
  and browser/app failures diagnostic.
- Clarified that Gemini narration sends narration text to Google's Gemini API.
